## Architecture Overview
Ecom OS is a **per-client-deployed monorepo template** (not multi-tenant SaaS). The universal Next.js 16 storefront (App Router, RSC-first) talks to one backend at a time through a single typed `EcomEngine` interface (ADR-004). `packages/ecom-engine` is the zero-runtime-dep contract; `packages/engine-woocommerce` and `packages/engine-vendure` are the two implementations. An env-driven addon loader (`scripts/generate-addons.ts`) tree-shakes disabled addons at build time (ADR-007). UI components **never** import an engine-specific package — only the `EcomEngine` contract (CI-enforced).

**Two non-negotiable laws (CI-enforced):**
1. No UI component imports an engine-specific module → everything through `EcomEngine` (ADR-004).
2. Vendure core is never modified — plugins only (ADR-002).

## Tech Stack
> Pinned by `CAHIER-DE-CHARGES.md §2`. Do not deviate without an ADR amendment.

- **Runtime:** Node.js 22 LTS · **Package manager:** pnpm ≥ 9 (monorepo)
- **Frontend:** Next.js 16 (App Router, RSC-first, Turbopack) · React 19
- **Language:** TypeScript 5.5+ strict (no `any`, no implicit)
- **Styling:** Tailwind CSS v4 (CSS-first `@theme`) · **UI primitives:** shadcn/ui (copied-in, on Radix) — owned source, not a runtime dep
- **Forms:** React Hook Form + Zod (shared schemas with server actions)
- **Animations:** GSAP via `@gsap/react` `useGSAP` hook (RSC-island only)
- **GraphQL client:** `graphql-request` (tiny, RSC-friendly)
- **State:** Zustand + React Context (cart/UI only) — *not* Redux (see RESEARCH.md conflict)
- **WC engine:** WordPress 6+ · WooCommerce 9+ · WPGraphQL 2+ (reads via GraphQL, writes via WC REST)
- **Vendure engine:** `@vendure/core` pinned, plugin-only · PostgreSQL 16 · Redis 7 (Sprint D)
- **Testing:** **Vitest** (unit/integration) + **Playwright** (E2E) — *not* Jest/Cypress (per Cahier §2)
- **Code quality:** ESLint v9 flat (`eslint-config-next`) · Prettier + Tailwind plugin · Husky pre-commit
- **Security scans:** Gitleaks + Trivy + Semgrep
- **CI:** GitHub Actions · **Deploy:** SSH+rsync+PM2 (WC/Hostinger) · Docker Compose (Vendure/VPS)

## Interface Drift — Known Issue (resolve in Section 01)
The shipped stub `packages/ecom-engine/src/interface.ts` predates ADR-004 and drifts in **3 ways**:

| Issue | Shipped stub | ADR-004 canonical | Fix in §01 |
|-------|--------------|--------------------|-----------| 
| Method names | `getProducts(limit?)` | `listProducts(query)`, `getProduct(slug, locale)`, `listCategories(locale)` | rename + add |
| Missing verbs | no checkout/payment verbs | `initCheckout`, `placeOrder`, `markOrderPaid`, `listCustomerOrders` | add |
| Money type | `price.amount = 19.99` (float) | `amount_minor: number` (int minor units) per ERD §1 + Cahier §8.14 | change type, no floats |

Do **not** build Section 05+ against the stub interface — it will be hardened first.

## File Map
> Aligned to Cahier §4 monorepo structure. `engine-*`, `addons-*`, `ui`, `brand-config`, `ecom-engine` packages; `wp-epioso-*` / `vendure-epioso-*` plugins.

- `packages/ecom-engine/src/{types.ts,interface.ts,factory.ts,index.ts}` — contract (zero runtime deps)
- `packages/engine-woocommerce/src/{client.ts,mappers.ts,products.ts,cart.ts,orders.ts,auth.ts}` — WC impl
- `packages/brand-config/` + `apps/storefront/brand.config.ts` — per-deployment brand
- `packages/ui/` — shared shadcn-derived primitives
- `scripts/generate-addons.ts` → `apps/storefront/src/addons.generated.ts` (addon loader)
- `scripts/create-ecom-os.ts` + `templates/deployment/` — CLI
- `apps/storefront/src/app/(marketing)/...`, `src/features/{home,catalog,pdp,cart,checkout,account}/...` — storefront
- `packages/addons-i18n/{register.ts,disable.ts,locales/{fr,ar,en}.json,middleware.ts}` — i18n addon
- `packages/addons-multi-payment/{register.ts,interface.ts,registry.ts,providers/{cod,stripe,cmi}/}` — payment addon
- `apps/storefront/src/app/api/webhooks/{stripe,cmi}/route.ts` — webhook receivers
- `apps/storefront/src/middleware.ts` — security headers, rate limits, locale routing
- `.github/workflows/ci.yml`, `scripts/check-engine-imports.sh`, `scripts/check-vendure-pristine.sh` — CI

## CI Gates (non-negotiable, Cahier §10)
- ❌ `engine-*` imported outside `lib/engine.ts` → fail (ADR-004)
- ❌ `node_modules/@vendure/**` modified → fail (ADR-002)
- ❌ Secret in client bundle / Gitleaks hit → fail
- ❌ Critical CVE (Trivy) → fail
- ❌ Type error / coverage < 70% on packages / build fail → fail
