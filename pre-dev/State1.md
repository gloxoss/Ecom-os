  What's Left for MVP

  Blocker-level (must have before first client):

  1. Missing screens: Cart page (S-20), Order detail (S-37), Search (S-13),     
  Profile (S-35), 404 page
  2. Missing screen states: loading skeletons + error boundaries on all existing
   screens
  3. Footer + BreadcrumbBar — used by every screen, not built
  4. Real WC integration test — everything has run against FakeEngine; one      
  end-to-end test against an actual WC sandbox needs to happen
  5. Staging deployment — Step 15 (run deploy-hostinger.ts against a real host) 

  Nice-to-have for v1:
  - WP i18n companion plugin (Step 13) — lets merchant edit strings without     
  redeploy
  - Password reset confirm page (S-34)
  - Address book (S-38)
  - Legal pages (static templates)

  What NOT to build next (defer to v1.1): Vendure engine, PayPal, abandoned     
  cart, shipping calculator.

  ---
  So if you want to bring in more tools/agents now: the highest-value targets   
  are Cart page + Order detail + 404 + Footer + loading states — those unlock   
  the last 15% to get to a deployable, client-showable MVP.
