# Market Opportunity — Ecom OS

## TL;DR

Ecom OS targets a real, expanding wedge: the **Moroccan + MENA e-commerce build market**, riding on top of the **global headless-commerce wave**. Local online-shopper count is up **65% in five years** while the local agency supply is still hand-building WooCommerce sites one at a time. A productized dual-engine starter kit captures the speed gap.

---

## 1. TAM / SAM / SOM

### TAM — Global headless commerce platforms
- **~USD 1.7–2.1B in 2025**, **~22% CAGR**, reaching **~USD 7B by 2032** (Cognitive Market Research, 2025; Coherent Market Insights, 2026).
- Broader "headless commerce platforms + services" definition: **USD 8.1B (2025) → USD 46.7B (2035) @ 19.1% CAGR**.
- North America = 38.6% share; APAC growing fastest (~25% CAGR).
- Not directly addressable for EPIOSO — context only.

### SAM — MENA e-commerce build & customization spend
- MENA e-commerce GMV: **USD 34.5B (2024) → USD 57.8B (2029)** at ~13% YoY (Digital Commerce 360 / RedSeer, 2025).
- Online retail penetration: **9% → 16% by 2030** on a USD 750B regional retail base.
- UAE alone: **USD 8.8B (2024) → USD 13.8B (2029)**.
- A conservative 1–2% of GMV reinvested in storefront tech each year = **USD 350M–700M/yr addressable build/customization spend across MENA**.

### SOM — Moroccan e-commerce build market (EPIOSO's realistic reach)
- Morocco e-commerce GMV: **~USD 1.7B in 2025** (Statista/MWN, 2025); higher methodology (RaM): USD 3.10B (2024) → USD 3.51B (2029).
- Online shoppers: **24.9% of population in 2024, up from 15.1% in 2019 — +65% / +3.7M shoppers** (Morocco World News, 2025).
- ~100+ active Moroccan web/digital agencies (Sortlist, TechBehemoths, 2026).
- Typical new e-commerce build: **15K–60K MAD** (Web Success, AzulWeb, ALTER WEB, 2025–2026); premium tier reaches 150K MAD.
- Estimated **~500 new e-commerce builds/year nationally × ~30K MAD avg = ~15M MAD (~USD 1.5M)** in annual addressable build spend in Morocco alone — small in absolute terms but **growing fast** and **EPIOSO only needs 0.5–1% of it** (5–10 client builds/yr at premium pricing) to be highly profitable.

EPIOSO does **not** need to win the market. It needs ~6–12 builds/year at 40–80K MAD using Ecom OS.

---

## 2. Demand-side trends ("why now", 2026)

1. **AI-mediated commerce is forcing composable architectures.** Shopify now positions Hydrogen as "the default React frontend for AI-mediated commerce" (Weaverse, 2026). Stores must be machine-readable, fast, and structured — exactly what a headless Next.js + GraphQL/REST stack delivers. Templated WooCommerce sites won't survive this transition.
2. **Composable / MACH adoption has reached the SMB tier.** Vercel + Shopify Hydrogen + open-source headless backends (Vendure, Medusa, Saleor) have collapsed the price floor. SMBs can now afford the architecture that previously cost USD 100K+ — *if* someone packages it for them. Ecom OS is that packaging.
3. **MENA-specific payment + language fragmentation is a moat.** Generic SaaS storefronts and open-source templates assume Stripe + LTR English. Real Moroccan/MENA commerce needs **COD, CMI, Stripe, multi-currency, AR/FR/EN with RTL**, and increasingly **multi-branch fulfillment**. Pre-wired addons for these are an immediate, defensible differentiator.

---

## 3. Supply-side gap

What Moroccan competitors currently offer:
- Templated WooCommerce with copy-paste plugin stacks — slow, fragile, dated DX.
- One-off "custom" PHP builds — unmaintainable, vendor-lock to the agency.
- A handful of agencies dabble in Shopify, almost none in headless Next.js.

What none of them offer:
- A **dual-engine** product line (Woo for SMB, headless Vendure for scale).
- Pre-wired **MENA addons** (CMI + COD + AR/FR/EN + multi-branch).
- **Reusable architecture** that compresses the next client to weeks instead of months.

This gap is Ecom OS's wedge.

---

## 4. Timing rationale

- **2024–2025 inflection in MENA**: shopper count surged ~65% in five years; payment infrastructure (CMI, Stripe MENA, COD aggregators) matured in parallel.
- **Vendure went GPLv3 with a plugin exception in July 2024** — perfect timing to base an addon-first product on top.
- **Next.js 16 + RSC + App Router + Tailwind v4** are stable enough in 2026 to be a long-term frontend choice without rewrite risk.
- EPIOSO already has the stack (Next.js, NestJS, Hostinger, Docker) — the marginal cost of building Ecom OS is one engineer's part-time time, not a funded R&D effort.

The window is open now; it will not stay this clean for more than 12–18 months before a regional competitor productizes the same pattern.
