## Usage Rules

- Do not ask the generator to recreate an exact Angelina logo or exact product label.
- Prefer "Angelina Paris inspired" over "exact Angelina packaging".
- Use "no visible logos, no readable text, no fake brand marks" in prompts.
- If an actual licensed Angelina asset is later approved, keep it as photography and do not regenerate it.
- For generated objects that resemble branded packaging, make the label blank or abstract.
