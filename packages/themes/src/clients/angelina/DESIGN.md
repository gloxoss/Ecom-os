# Angelina Paris Design Kit

## Visual Theme & Atmosphere
Warm, elegant, and heritage-inspired. Captures the ambiance of a classic Parisian tearoom with modern refinement.

## Color Palette & Roles
- **Warm Brown (#3f100a):** Primary text and dominant contrast color.
- **Café (#aa631a):** Primary action color, used for primary buttons and active states.
- **Gold (#c69951):** Secondary brand color, used for cards and elegant accents.
- **Old Peach (#d9a594):** Muted background and secondary text elements.
- **Vieux Rose (#ffcebf):** Accent color for soft highlights.
- **Soft Peach (#fff5f2):** Subtle borders and input backgrounds.
- **White (#ffffff):** Clean background base.

## Typography Rules
- **Headings:** Sentient Variable (serif), applied to all h1–h6. Expressive and elegant.
- **Body:** Inter Tight Variable (sans-serif). Clean readability for long-form content.
- **Labels/Overlines:** 14px uppercase medium, `tracking-[1.4px]` for refined categorization.

## Component Stylings
- **Buttons/Badges:** Pill-shaped (`rounded-full` / 100px radius) for all CTAs and badges.
- **Cards:** Highly rounded corners (`rounded-2xl` / 16px radius).
- **Shadows:** Warm-tinted only (`rgba(0,0,0,0.11)`).

## Layout Principles
- Generous whitespace.
- Fluid typography and responsive scaling.
