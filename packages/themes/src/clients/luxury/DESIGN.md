# Ecom-os Design Patterns: Luxury Theme

Dark mode only. Heavy use of serif fonts and high-contrast element separation.

## Core Rules
- Primary backgrounds must be nearly black.
- Use primary white color for text to achieve high contrast.
- Prefer elegant, slower Framer Motion transitions (e.g., duration: 0.8s, ease: [0.16, 1, 0.3, 1]).
