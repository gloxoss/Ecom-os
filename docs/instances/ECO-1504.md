# ECO-1504 — hide the default and fixture categories from the ParaLoca landing page

Instance-only change. Nothing in this task touches the starter.

## Ledger row

| N | Problem | Found where | Root cause | Instance fix | Status |
| --- | --- | --- | --- | --- | --- |
| 23 | The landing page offered shoppers WordPress's empty default bucket and the EcomOS test fixtures as product categories | Screenshotting the running instance (`docs/instances/design/landing-desktop-before.png`) and `curl https://paraloca-store.local/wp-json/wc/v3/products/categories` | The instance's landing component rendered every category the engine returned. The store carries two categories that exist for machinery reasons, not shopping: `uncategorized` (WooCommerce's built-in default, product count 0) and `ecomos-test-fixtures` (the fixtures the engine, live specs and acceptance runs depend on, count 3). Both were shown as the only two category pills on the home page. | `apps/storefront/src/client-shells/paraloca/landing.tsx` filters them out by slug before rendering. The fixtures stay in the store, so every test that depends on them keeps passing. | FIXED |

Deliberately not done: deleting the categories from WooCommerce. The fixtures back the engine and live specs, and `uncategorized` cannot be removed from WooCommerce anyway.
