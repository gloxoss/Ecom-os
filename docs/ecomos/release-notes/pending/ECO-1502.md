# ECO-1502 — the search box is translatable

## Ledger row

| N | Problem | Found where | Root cause | Starter fix | Status |
| --- | --- | --- | --- | --- | --- |
| 22 | The search box could not be translated | Translating the ParaLoca storefront into French | `SearchAutocomplete` hardcoded its user-visible copy in English: the submit button `Search`, the three suggestion group headings, the offline / unavailable / rate-limited messages, the empty-result sentence, the "see all results" line, and six `aria-label`s. The catalogue already carried an unused `search.button`, so the infrastructure existed and the component simply ignored it. | Every user-visible string now comes from the `search` namespace through `useTranslations`, including the aria-labels. `placeholder` and `inputLabel` remain optional props for a caller that translates its own copy, and fall back to the catalogue when omitted. No copy and no client text lives in the component. | FIXED |

## Migration note (next release)

- **What changed.** `packages/addons-i18n/locales/{en,fr,ar}.json` gained 23 keys under `search`, taking that namespace from 5 to 28 (en, fr and ar have identical key sets). `apps/storefront/src/components/search/search-autocomplete.tsx` reads them instead of holding literals.
- **Who is affected.** Every instance, for the better: the control now follows `ECOM_CLIENT_PROFILE`'s locale rather than sitting in English. No instance file needs editing.
- **Exact steps.** None. The keys ship with the addon.
- **How to confirm.** Render the search control under the French locale and check the submit button reads `Rechercher` and the mobile trigger is labelled `Ouvrir la recherche`.
- **How to roll back.** Revert the commit; the component returns to its English literals and the extra keys become unused.
- **Note for the RFQ/search lane:** the added keys are new names under an existing namespace, so nothing that already read `search.title`, `search.placeholder`, `search.empty`, `search.results` or `search.button` changes meaning.

## Changelog line

- i18n: the storefront search box is now fully translatable. All visible copy and aria-labels come from the `search` catalogue entries in English, French and Arabic instead of being hardcoded in the component.
